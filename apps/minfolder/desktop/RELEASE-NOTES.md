MinFolder Windows 0.3.0 시험판

- 균형 배치로 폴더 탐색·파일 목록·이동 검토를 한 화면에 배치했습니다. 경계선을 드래그하거나 방향키로 영역 크기를 조절하고 마지막 배치를 기억합니다.
- 저장 위치 탐색과 정리할 원본 목록을 분리했습니다. 목적지를 둘러보아도 원본 파일 목록을 유지하고, 이 폴더 파일 보기로 원본을 명시적으로 바꿉니다.
- 파일·저장 위치·상태를 간결하게 보여주고, 긴 경로와 추천 이유는 상세 보기로 제공합니다. 전체·이동 준비·확인 필요로 필터링하며 숨겨진 선택도 표시합니다.
- 승인 버튼에 실제 선택한 파일 수를 표시합니다. 필터·보기·배치 변경은 승인 대기를 보존하며 최종 확인 전에는 실제 이동하지 않습니다.
- 새 사용자는 열 탐색으로 시작하고 기존 지도·보기 설정은 유지합니다. 0.2.1의 최소화·종료 수정과 실제 Windows 창 제어 검사를 유지합니다.

Windows 10·11 x64용입니다. 이전 버전은 앱의 버전 버튼에서 업데이트를 확인할 수 있습니다. 설치 파일에는 Windows 게시자 인증서가 없어 확인 경고가 표시될 수 있습니다. 회사 SMB 환경은 별도 실기기 검증이 필요합니다.

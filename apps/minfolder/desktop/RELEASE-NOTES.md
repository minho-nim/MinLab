MinFolder Windows 0.2.0 시험판

- 열 탐색을 추가해 상위·하위 폴더를 가로로 이어 보고 경로를 눌러 돌아갈 수 있습니다. 기존 폴더 지도도 선택해 사용할 수 있습니다.
- `ㄱㄴ pdf` 같은 초성·여러 낱말 검색과 상위 경로가 포함된 검색 결과를 제공합니다. 검색은 불러온 이름만 대상으로 하며 새 디스크 읽기를 하지 않습니다.
- 웹도 큰 화면에서는 탐색·파일 목록·이동 승인을 한 화면에 배치합니다. 열의 폴더에 드래그해도 승인 목록에 추가되며 승인 전 실제 파일을 옮기지 않습니다.
- 기존 아이콘·파일명 추천·승인 이동·자동 업데이트 확인·다운로드를 유지합니다.

Windows 10·11 x64용입니다. 이전 버전은 앱에서 업데이트를 확인해 설치할 수 있습니다. 설치 파일에는 Windows 게시자 인증서가 없어 확인 경고가 표시될 수 있습니다. 회사 SMB 환경과 실제 업데이트 설치는 실기기 검증이 필요합니다.

# MinFolder | MinLab 내장 앱

이 ZIP의 파일을 MinLab 저장소의 apps/minfolder 안에 직접 올립니다. 배포 설정은 그대로 둡니다.
공개 주소는 https://minho-nim.github.io/MinLab/apps/minfolder/ 입니다.

## 탐색 보기와 이름 검색 (0.2.0)

### 균형 배치 (0.3.0)

900px 이상에서는 탐색 영역 아래 경계선을 드래그해 높이를, 파일 목록과 검토 영역 사이 경계선을 드래그해 너비를 조절합니다. 키보드 Tab으로 경계선에 이동한 뒤 방향키로도 조절할 수 있습니다. 마지막 배치를 해당 브라우저·앱에 기억하며 경로·파일 내용을 저장하는 설정은 아닙니다.

검토 목록은 파일·저장 위치·상태를 표시합니다. **전체 / 준비 / 확인 필요** 필터는 선택 상태를 바꾸지 않습니다. 현재 필터에 보이지 않는 선택은 `숨겨진 선택` 수로 표시하고, 승인 버튼은 전체 목록에서 실제 선택한 처리 대상 수를 보여 줍니다. `상세 보기`에서 원본·전체 목적지·추천 이유를 확인하거나 대기에서 제외합니다. 상태 미확정 파일은 위치 지정 전 승인할 수 없습니다.

웹의 고정 폴더·제외 규칙은 **설정 → 폴더 표시 설정**에서 사용할 수 있습니다. 탐색기에서 웹으로 추가한 파일은 계속 원본을 유지하고 복사하며, Windows 앱은 승인 후 실제 이동합니다. 새 사용자는 열 탐색으로 시작하고 기존 보기 설정은 유지합니다.

- **열 탐색**에서는 상위·현재·하위 폴더를 나란히 표시합니다. 폴더를 선택하면 오른쪽에 하위 폴더가 열리고, 위 경로를 눌러 상위로 돌아갑니다. 열의 폴더에 파일을 놓아도 기존 승인 목록에 추가됩니다.
- **폴더 지도**는 기존 가로 지도를 유지합니다. 보기 전환은 선택한 경로와 분류 대기를 유지하며 마지막 보기만 브라우저에 기억합니다.
- `ㄱㄴ pdf`, `송도 2026 xlsx`처럼 초성·여러 낱말·확장자로 검색합니다. 열 탐색의 결과에는 같은 이름을 구별할 수 있도록 상위 경로를 표시합니다. 검색 결과를 누르면 해당 위치의 파일 목록을 보여 줍니다.
- 검색은 **이미 읽은 이름만** 대상으로 합니다. 입력·보기 전환은 추가 디스크 읽기를 하지 않습니다. 파일 본문이나 드라이브 전체 색인을 만들지 않으며, 공유폴더의 필요한 가지를 열거나 더 읽기로 범위를 넓힙니다.
- 900px 이상 웹 화면도 한 화면에 탐색·파일 목록·승인을 배치합니다. 각 목록 안에서만 스크롤하고, 좁은 브라우저는 세로로 배치합니다.

구조 참고: [4Dir의 분할 탐색](https://4dir.net/ko/), [SpanFinder의 열 탐색](https://github.com/LumiBearStudio/SpanFinder), [FastFind의 초성 검색](https://fastfind.kr/). 기능 설명을 참고하고 MinFolder의 기존 모듈로 구현했으며 외부 앱 소스는 가져오지 않았습니다.

웹이 기본 진입점입니다. 상단 **설정 → 앱 설치 → Windows 앱 다운로드**에서 설치 파일을 받고, 설치 후 앱에서 기준 폴더를 다시 연결합니다. 웹의 연결·기록은 앱으로 자동 이전되지 않습니다. Windows 설치 파일에는 게시자 인증서가 없어 확인 경고가 표시될 수 있습니다.

웹 로고·탭 아이콘과 Windows 아이콘은 `branding/icon-source.png`의 승인된 동일 이미지를 사용합니다. 원본 그림은 수정하지 않고 Tauri의 `tauri icon`으로 필요한 크기와 ICO 형식만 생성합니다. `icon.png`와 `favicon.png`도 웹 배포에 포함됩니다.

- Chrome 또는 Edge에서 기준 폴더 하나를 연결합니다. 브라우저 권한이 유지되면 연결을 기억합니다.
- 처음에는 위쪽 폴더만 읽습니다. 깊은 폴더는 +를 눌러 엽니다. 큰 목록은 ‘다음 항목 보기’로 나눠 표시합니다.
- 검색은 읽어온 폴더와 파일을 대상으로 합니다. 분류 추천은 해당 파일명과 일치하는 계약 폴더만 추가로 확인합니다.
- 지도 파일을 직접 드롭하거나 추천 위치를 확인한 다음 승인하면 연결 범위 안에서 이동합니다.
- 탐색기에서 직접 넣은 파일은 원본을 유지하고 복사합니다.
- 작업 파일이나 경로는 서버에 올리지 않습니다.

- 선택 폴더 새로고침은 해당 폴더의 바로 아래만 갱신합니다. 큰 폴더는 다음 항목 보기로 이어서 확인하세요.
- 파일 이동 후 원본과 목적지만 갱신합니다. 목적지가 없거나 변경으로 확인되면 새 위치를 고릅니다.

- 기본 3단계는 기준 폴더 → 업무 분류 → 계약명입니다. 깊은 가지는 필요한 것만 펼칩니다.
- 지도 위에서 − / + 버튼이나 휠로 확대·축소하고, 휠 버튼을 누른 채 끌어서 이동합니다. 화면 조작은 파일 시스템을 다시 읽지 않습니다.

## Windows 앱

Windows 설치형 MinFolder는 [desktop/README.md](desktop/README.md)를 참고하세요. 파일명 추천·승인 이동·탐색기 드롭·기본 프로그램으로 파일 열기를 제공하는 별도 진입점이며 기존 웹 배포는 유지합니다.

## 확인한 화면

현재 소스의 홈을 Chromium, 1440×1000과 390×1000에서 확인함. 계정의 실제 브라우저 데이터와 분리된 컨텍스트를 사용함. 애니메이션 축소 상태로 기준 화면을 캡처함. 화면·데이터·인터랙션은 변경하지 않음.

현재 차콜·세이지 색상, Pretendard, 실제 프로젝트 화면, 비대칭 화면 비율과 프로젝트 중심 탐색은 유지할 가치가 있음. 장식용 AI 이미지, 보라색 그라데이션, 허구의 성과를 발견한 것으로 기록하지 않음. 전면 재설계보다 polish mode가 적합함.

## 진단과 제안

| 위치 | 확인 값 | 제안 |
| --- | --- | --- |
| 모바일 `.hero-project-label span` | 10px / 행간 15px | 12px / 행간 18~20px |
| 데스크톱 프로젝트 분류 | 11px | 12px로 일관되게 정리 |
| 제목 | 데스크톱 56px·650·자간 -3.08px, 모바일 32px·650·자간 -1.76px | 기존 글꼴·문구·크기를 유지하고 600·자간 -0.03em 범위 검토 |
| 화면 모음 gap | 데스크톱 18px, 모바일 10px | 16px·12px로 정리 |
| 프로젝트 이름 padding | 10px 0 | 12px 0 |
| 홈 하단 안내 margin-top | 25px | 24px |
| 짧은 전환 선언 | 일부 `transition: .2s` | 실제 변화하는 opacity·transform 등을 명시 |

실제 스크린샷과 그 안의 UI는 임의로 다시 그리거나 내용을 바꾸지 않음. 기존 사용자 확정 사항인 커서 반응, 스크롤 탐색, 전체 화면 메뉴와 애니메이션 축소 지원은 유지함. 스킬의 일반적인 parallax 제거 제안보다 기존 사용자의 구체적인 인터랙션 지시를 우선함.

## 다섯 줄 방향

- Product: 직접 만든 앱·게임과 개발 과정을 탐색하는 아카이브.
- Character: 차분함, 명확함, 실험성.
- World: 개발 작업실과 프로젝트 기록.
- Moments: 실제 앱 화면과 스크롤형 대표작 미리보기.
- Signature: 프로젝트 이름·날짜·버전으로 이어지는 탐색.

## 다음 단계

스킬의 Run it 4번은 진단과 방향을 먼저 보여주고 답변을 기다리도록 명시함. 설치·진단과 `preview/` 비교 시안을 먼저 제시했으며, 사용자의 “진행” 답변 후 간격 → 색상 → 아이콘 → 문구 → 타이포그래피 → 레이아웃 → 세부 요소 → 화면 → 동작 순으로 점검하고 필요한 항목만 정돈함. 범위 밖의 기능·데이터·메인 문구 변경은 포함하지 않음. 유료 이미지 생성이나 영상 제작은 요청받지 않았으며 진행하지 않음.


## 적용한 패스

1. 간격: 화면 모음 16px(모바일 12px), 이름 영역 12px, 제목 위 16px, 소개 링크 위 12px, 하단 안내 위 24px로 정돈함.
2. 색상: 기존 차콜·세이지 및 텍스트 역할을 유지함.
3. 아이콘: 기존 Lucide 아이콘과 탐색 의미를 유지함.
4. 문구: 사용자가 확정한 한국어 문구와 실제 프로젝트 내용을 유지함.
5. 타이포그래피: 제목 굵기 650 → 600, 자간 -0.055em → -0.03em, 프로젝트 분류 12px·행간 20px로 조정함.
6. 레이아웃: 기존 비대칭 화면 비율·구획 순서·모바일 읽기 순서를 유지함.
7. 세부 요소: 동일한 프로젝트 이름/분류 영역 간격을 일관되게 맞춤.
8. 화면: 기존 실제 앱 스크린샷을 유지함. 이미지 생성이나 재구성 없음.
9. 동작: 설명의 전환 대상을 opacity·transform으로 명시함. 사용자가 확정한 커서·스크롤 반응과 애니메이션 축소 지원을 유지함.

운영 배포와 별개로 검토용 비공개 미리보기를 갱신하며, 공개 운영 반영은 이 변경을 검토한 뒤 진행함.

## 적용 후 검증

- Vite 포트폴리오 빌드 통과. 스킬과 비교 문서를 Tailwind 스캔 대상에서 제외해 스킬 예제 클래스가 앱 CSS로 생성되지 않게 함.
- Chromium 기존 회귀 검증 통과: 실제 데이터 보존, 검색·필터 URL과 뒤로 가기·스크롤 복원, 개발일지·프롬프트·초안·JSON 복원·이미지 업로드, 키보드 메뉴·터치 탐색·애니메이션 축소, 320·375·390·768·1280·1440px 화면.
- 스킬 업스트림 파일 14개와 원본 라이선스의 바이트 일치를 확인함.
- 기존 프로젝트 데이터·개발일지·프롬프트 원본은 수정하지 않음.

# Crossroads 공개 플레이 및 목록 연결 수정

2026-10-29 사용자 요청에 따라 Crossroads 게임을 MinLab의 기존 GitHub Pages 아래에 배포함.

- 공개 주소: https://minho-nim.github.io/MinLab/apps/crossroads/
- 원본 코드: 기존 비공개 Crossroads 저장소의 `b9b4aaa` 빌드임.
- 게시 파일: `public/apps/crossroads/`에 Vite가 생성한 HTML·JS·CSS·런타임 이미지 파일만 복사함. 원본 TypeScript, 소스맵, 로컬 저장, 작업 시안·백업 및 화면 검증용 HTML은 포함하지 않음.
- 게임 소스가 바뀌면 Crossroads에서 빌드 후 해당 배포 파일도 갱신해야 함. 현재 이 빌드를 원본 저장소에서 자동 가져오는 기능은 없음.

기존 방문자에게 Crossroads가 보이지 않았던 원인은 `minlab_public_catalog_v6` 표시가 설정되면 목록 전체를 다시 확인하지 않는 처리였음. 이제 프로젝트 ID별 연결 이력을 보관해 새 항목만 한 번 추가함. 기존 설명·일지·프롬프트·사용자 주소를 덮어쓰지 않고, 삭제한 기존 프로젝트와 이미 연결했다가 삭제한 Crossroads도 복원하지 않도록 처리함. 기록 데이터는 올라갔지만 실제 사용자 화면까지 확인하지 못한 이전 보고를 보완하는 수정임.

예전 테스트에 있던 고정 프로젝트 수·프롬프트 수 가정은 현재 원본 항목과 고유 ID·내용 보존을 검사하도록 정리함. 새 프로젝트가 추가되어도 이전 데이터가 사라지거나 중복되는지 확인하는 취지를 유지함.

공개 사이트와 로컬 미리보기는 주소가 달라 게임 진행 저장 공간도 다름. 기존 로컬 저장을 삭제하거나 이전했다고 처리하지 않음. 기록과 앱의 공개 반영 결과는 GitHub Pages 배포 후 별도로 확인함.

2026-10-30: 시작 목표 안내, 소개 탭, 모바일 카드 배치, 대사 나누기와 선택지 전문 보기 빌드로 갱신함. 자동 테스트 74개·타입 검사·빌드 통과. 최종 가로 화면과 공개 화면의 시각 재검증은 앱 브라우저 연결 문제로 미완료임.

2026-10-30 후속 수정: 대사 쪽수·이전·다음을 제거하고 전체 대사를 한 스크롤 창에 표시함. 주요 인물 사진 칸과 모바일 설명·표정의 너비를 정리함. 자동 테스트 74개·타입 검사·빌드 통과. 실제 430×850 소개 및 320×568 본문 내부 스크롤 확인함.

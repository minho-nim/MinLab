MinFolder Windows 0.1.1 시험판

- 승인된 새 MinFolder 아이콘을 창 제목·버전창·작업 표시줄·실행 파일·설치 파일에 동일하게 적용했습니다.
- 웹 버전은 기본 진입점이며 설정의 앱 설치 안내에서 Windows 앱을 받을 수 있습니다.
- 기존 한 화면 폴더 지도와 파일명 추천·승인 이동, 자동 업데이트 확인·다운로드 기능을 유지합니다.

Windows 10·11 x64용입니다. 이전 0.1.0은 앱에서 업데이트를 확인해 설치할 수 있습니다. 설치 파일에는 Windows 게시자 인증서가 없어 확인 경고가 표시될 수 있습니다. 회사 SMB 환경과 실제 다음 버전 설치는 실기기 검증이 필요합니다.

MinFolder Windows 0.2.1 시험판

- 창 닫기 요청 후 실제 종료 단계에 필요한 권한을 추가해 닫기 버튼과 Alt+F4가 동작하지 않던 문제를 수정했습니다.
- 종료 확인창 중복 표시를 막고, 취소하면 작업 상태를 복구합니다. 종료 오류를 화면에 표시하며 다시 시도할 수 있습니다.
- 파일 이동·업데이트 설치 중에는 종료를 차단하고, 종료 확인 중 새 파일 작업을 시작하지 않습니다. 승인하지 않은 파일은 옮기지 않습니다.
- Windows 빌드 검사를 창 실행뿐 아니라 정상 닫기와 프로세스 종료까지 확인하도록 강화했습니다.

Windows 10·11 x64용입니다. 이전 버전은 앱의 버전 버튼에서 업데이트를 확인하거나 새 설치 파일로 갱신할 수 있습니다. 설치 파일에는 Windows 게시자 인증서가 없어 확인 경고가 표시될 수 있습니다. 회사 SMB 환경은 별도 실기기 검증이 필요합니다.

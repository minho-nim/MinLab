MinFolder Windows 0.1.0 시험판

- 원본의 가로 폴더 지도와 녹색 화면을 유지하고 한 화면에 탐색·파일 선택·이동 승인을 배치했습니다.
- 폴더는 필요한 가지만 읽으며, 큰 지도와 긴 목록은 영역 안에서 탐색합니다. 승인 버튼은 항상 보입니다.
- 파일명에서 계약·팀과 문서 종류를 찾아 폴더를 추천합니다. 승인한 파일만 실제 이동하며 같은 이름은 덮어쓰지 않습니다.
- 파일명 클릭으로 Windows 기본 프로그램을 열고, 탐색기에서 파일을 끌어와 분류할 수 있습니다.
- 창 제어와 버전 표시를 제공하고 업데이트를 자동 확인·다운로드합니다. 사용자가 설치를 시작해야 적용하며 파일 이동 중에는 설치하지 않습니다. 업데이트 서명과 서명된 버전을 검증합니다.

Windows 10·11 x64, Microsoft Edge WebView2가 필요합니다. 런타임이 없으면 최초 설치에서 Microsoft 공식 런타임을 다운로드합니다. 앱 데이터와 경로·파일명·이동 기록은 로컬에 저장하며, 버전 확인·업데이트 다운로드에는 GitHub를 사용합니다.

이 설치 파일에는 Authenticode 인증서가 없습니다. 회사 보안 정책에 따라 실행이 제한될 수 있습니다. 실제 회사 SMB 서버의 권한·파일 잠금·성능과 다음 버전으로의 업데이트 설치는 별도 실기기 검증이 남아 있습니다.

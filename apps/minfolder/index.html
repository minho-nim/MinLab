Windows 앱 다운로드 ↓
  1. 다운로드한 MinFolder-Setup.exe를 실행하세요.
  2. 설치한 앱에서 기준 폴더를 다시 연결하세요.

웹의 폴더 연결과 기록은 앱으로 자동 이전되지 않아요. 설치 후 새 버전은 앱에서 확인·다운로드하고, 승인하면 적용해요.

게시자 인증서가 없어 Windows 확인 경고가 표시될 수 있어요. 회사 PC는 사내 프로그램 설치 정책을 확인해 주세요.

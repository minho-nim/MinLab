# 개발 기록 운영 메모

- 개발일지·프롬프트는 사용자가 업데이트를 요청할 때만 Codex가 작성·반영함.
- 게시된 기록은 일반 개발일지·프롬프트 목록에 바로 표시함. 초안 목록·검토·저장·새로고침 버튼과 배포·기록 원본 링크는 화면에서 제거함.
- 기록 원본: `.minlab/records.json`. 작업 설명·사용한 프롬프트·결과·관련 출처를 함께 보관함.
- 게시 데이터: `public/data/github-drafts.json`. 파일명은 기존 경로 호환을 위해 유지하며, 화면상 초안으로 취급하지 않음.
- 변경 이력: Git 커밋 이력에서 원본 파일의 변경 전·후 내용을 확인할 수 있음.
- 사용자 브라우저의 별도 수정·추가·삭제는 보존하며, JSON 백업·복원을 지원함.
- 이 메모는 운영 참고용이며, 별도의 개발일지나 프롬프트 항목으로 등록하지 않음.
